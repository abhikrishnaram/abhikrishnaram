I build and run platforms full-time, from the UI people click on down to the infrastructure it runs on. Lately that's mostly system design, IaC and CI/CD: provisioning, automating and scaling the plumbing so every piece of code has somewhere to run without anyone praying 🤞.

Sometimes the answer is a distributed system. Sometimes it's a monolith with a bash script run by a cron job. Both have their place; one just looks better in a diagram.

**Things I've built**

- **[Verifycate](https://verifycate.com)** — certificate generation and distribution, 20,000+ certificates issued (built most of the frontend, co-built the backend)
- **[Ulsav](https://ulsav.com)** — event ticketing, ₹1.5 crore+ processed, 75k+ live check-ins (founding member; owned the infra, contributed to development)
- **[Chaya UI](https://github.com/four43labs/chaya-ui)** — data-first React component library (contributor)
- CTF infrastructure for Pentathon 2024 (8,900+ players), bi0sCTF, and the International Cybersecurity Challenge in San Diego & Chile
- **[Serkhet](https://github.com/abhikrishnaram/serkhet)** — IoT malware monitoring with lightweight syscall tracing (paper accepted at IEEE ICCCNT 2025)
- **[Concierge](https://github.com/abhikrishnaram/concierge)** — self-hosted webhook + cron dispatcher so deploys don't need SSH, screenshots and crossed fingers (Go)
